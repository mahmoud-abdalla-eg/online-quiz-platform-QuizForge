# MongoDB Data Model

MongoDB Atlas is used for persistence. The Java backend connects using the official MongoDB Java Sync Driver.

## Environment

```text
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster-host>/
MONGODB_DATABASE=online_quiz_platform
```

## Collections

### users

Stores students and admins.

| Field | Type | Description |
| --- | --- | --- |
| _id | int | Numeric user id generated by `counters` |
| name | string | User display name |
| email | string | Unique login email |
| password | string | Demo password |
| role | string | `ADMIN` or `STUDENT` |
| createdAt | string | Creation time |

### quizzes

Stores quizzes with embedded questions and options.

| Field | Type | Description |
| --- | --- | --- |
| _id | int | Numeric quiz id generated by `counters` |
| title | string | Quiz title |
| description | string | Quiz description |
| durationMinutes | int | Suggested quiz duration |
| createdBy | int | Admin user id |
| createdAt | string | Creation time |
| questions | array | Embedded question documents |

Question document:

| Field | Type | Description |
| --- | --- | --- |
| id | int | Numeric question id |
| text | string | Question text |
| options | array | Multiple-choice options |

Option document:

| Field | Type | Description |
| --- | --- | --- |
| id | int | Numeric option id |
| text | string | Option text |
| correct | boolean | Whether this option is correct |

### attempts

Stores submitted student attempts.

| Field | Type | Description |
| --- | --- | --- |
| _id | int | Numeric attempt id generated by `counters` |
| userId | int | Student user id |
| quizId | int | Quiz id |
| score | int | Correct answer count |
| totalQuestions | int | Number of questions |
| submittedAt | string | Submission time |
| answers | array | Selected answers |

Answer document:

| Field | Type | Description |
| --- | --- | --- |
| questionId | int | Question id |
| optionId | int | Selected option id |
| correct | boolean | Whether the selected option was correct |

### counters

Stores numeric id counters for collections that need frontend-friendly integer ids.

| Field | Type | Description |
| --- | --- | --- |
| _id | string | Counter name, such as `users`, `quizzes`, `questions`, `options`, or `attempts` |
| seq | int | Latest generated id |
